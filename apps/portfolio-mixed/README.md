# Haziq Asyraaf's Portfolio

Professional portfolio website showcasing cybersecurity expertise, RPA automation projects, and technical capabilities.

🌐 **Live Site:** [https://haziqhtech.sg](https://haziqhtech.sg)

## Features

- 📝 **Technical Blog** - Deep dives into cybersecurity, RPA, and automation
- 💼 **Project Showcase** - Real-world implementations with detailed case studies
- 💬 **Interactive Comments** - Powered by Neon Postgres with real-time engagement
- 📊 **Analytics Dashboard** - MongoDB-powered project insights
- 🎯 **Timeline & Resume** - Professional journey and achievements
- 📧 **Contact Form** - Direct communication channel

## Tech Stack

### Frontend
- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Shadcn UI Components**
- **MDX** for blog content

### Backend & Database
- **Neon Postgres** - Comments and analytics (serverless PostgreSQL)
- **MongoDB Atlas** - Projects and dynamic content
- **Prisma ORM** - Type-safe database queries

### Deployment
- **Vercel** - Edge deployment with global CDN
- **GitHub** - Source control and CI/CD

## Key Highlights

- ✅ **100% TypeScript** - Type-safe throughout
